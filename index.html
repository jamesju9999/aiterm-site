AI 再厲害，
工作還是得有人安排

AITerm 是跨平台 AI 智慧終端機。除了接雲端模型，更能串接本地端模型，省下 token 費用、資料不外送；或用 Claude Code CLI 橋接任何你想接的模型。
更重要的是，它把 AI 的產出當成工作來管：工作看板讓你把事情排進佇列，AITerm 自動派給 Claude Code 執行、追蹤結果、整理成報告。
自主代理循環、多資料庫連線、知識庫與 MCP 工具全都內建，基於 Tauri 2、React 19 與 Rust 打造。

工作管理與分派

把工作排進去，AITerm 自動派給 Claude Code

模型已經能寫程式、跑指令、多步驟完成整件任務。但你仍然一次只盯得住一件事： 下指令、等它跑完、看結果、再下一件。
瓶頸早就不在模型能不能做，而在你一次能盯幾件。

01

算力變便宜了，你的注意力沒有

同時跑十個 AI 任務在技術上毫無問題，難的是你記不住哪件在跑、哪件跑完了、哪件失敗要重來。缺的不是更強的模型，是一個放得下這些事的地方。

02

需求寫清楚，比催 AI 更有效

同一件事講得清楚與講得含糊，結果天差地遠。與其反覆修正，不如一開始就把目標、範圍、限制與驗收標準寫下來——這也是一份工作能被交出去的前提。

03

做完的事要留下記錄

跑完就消失的自動化沒有累積。哪件做了、怎麼做的、結果如何，要能回頭查、能整理成報告交出去，那才算是工作，不只是一次執行。

一張卡片，就是一件交出去的工作

把想做的事寫成卡片：標題、要在哪個資料夾做、詳細指示，需要的話附上檔案。 拖到「待執行」，AITerm 就會開一個分頁、啟動 Claude Code、把指示送過去， 做完自動搬到「已完成」並標上成功或失敗。

一次排好幾件，晚上再看結果——不必守在電腦前一件一件下指令。 同時執行幾件由你決定，不會一次全部塞出去。

  • 互動模式：需要邊做邊討論的工作，不佔並行額度，也不會被判定卡住
  • 專案：卡片歸屬於專案，專案是磁碟上自成一體的資料夾，複製即可搬移或分享
  • 搜尋：依標題、內容或工作目錄即時過濾四個欄位

AI 工作報告

把一個專案的看板整理成一份文件——AI 讀過每一張卡片（含已完成工作的完整對話記錄），產出排版好的報告存進專案累積成歷史。已完成的摘要只整理一次就快取起來，第二次產報告只處理新的部分。

AI 潤飾需求

工作內容隨手打幾句，按下潤飾，AI 會改寫成一份能直接執行的指示：目標、範圍、限制、驗收標準，而且不會自己加上你沒要求的工作。不滿意一鍵還原。

封存

做完的事不會無止境堆積。單張或整欄一次收起，看板只留下正在進行的。封存不是刪除——卡片、對話記錄、附件全部留著，可搜尋、可翻閱、可放回看板。

核心功能

把 AI 直接嵌入你的工作流，不需要切換視窗

/ai

AI 指令工作流

在終端機輸入 /ai <查詢>，即時生成 shell 指令並顯示風險等級，確認後一鍵執行。

💰

本地模型・省 token 費用

除了雲端供應商，AITerm 也能接 Ollama、LM Studio、oMLX 這類本地 / OpenAI 相容端點——推論在自己機器上跑，不花 API 費用、資料不外送，量大的自動化任務尤其划算。或用 Claude Code 橋接，讓 Claude Code CLI 跑在你手邊任何一個供應商上。

🧱

結構化指令區塊

每個指令與其輸出都會渲染成獨立卡片，而非傳統終端機的原始捲動畫面。即時終端機視窗只在指令執行中才自動展開，閒置時自動收合，畫面保持乾淨。

▶

自主代理循環

輸入 /agent 啟動多步驟代理模式，AI 自動規劃並執行複雜任務，危險操作自動退回手動確認。

🔁

LoopStudio 循環工程

「循環工程」讓 AI 自主拆解、執行任務，不必一問一答反覆確認——主控代理持續分派子代理執行，直到目標完成才停止，安全閘門與即時執行追蹤全程把關。

📋

工作看板・自動派工

把工作寫成卡片排進佇列，AITerm 自動開分頁、啟動 Claude Code、送出指示，完成後標記成功或失敗。含專案、互動模式、對話記錄、AI 工作報告與封存。看詳細 →

💻

程式庫協助

獨立分頁，讓 AI 針對任意專案目錄回答問題——自動掃描檔案樹、搜尋並讀取原始碼，可繪製 Mermaid 圖表，對話還能匯出成 Markdown。

💬

多輪對話側邊欄

終端機旁內建具備上下文記憶的 AI 對話視窗，問題排解、程式碼生成、靈感發想一次搞定。

📊

AI 文件與圖表面板

AI 產生的報告、比較表格與圖表會在對話右側開一個排版好的面板，而不是塞成聊天泡泡裡的原始碼。長條圖、折線圖、圓餅圖直接畫出來，可切換成表格檢視看確切數字，也能一鍵存成 HTML 檔。終端機與遠端 AI 面板、程式庫協助、知識庫、資料庫與跨資料庫問答皆適用。

📚

知識庫

建立筆記本並指定一個資料夾，AITerm 會自動切割、嵌入（Embedding）並索引其中的所有文件，之後即可用自然語言提問，回答附上原始文件引用來源；支援 Ollama 與任何 OpenAI 相容的 Embedding 供應商。

🗄

多資料庫連線

原生支援 PostgreSQL、MySQL、SQLite、ODBC。DB2 透過內建 Java JDBC Sidecar 在 macOS 與 Windows 均可使用，無需安裝驅動程式。

📁

檔案總管

內建側邊欄檔案瀏覽器，與終端機工作目錄雙向同步：終端機切換路徑即時反映在檔案總管，點擊「cd」按鈕或輸入框內建的資料夾選單也能立即把終端機切換到該目錄。

🔖

指令搜尋與書籤

Ctrl+F 可跨所有區塊歷史搜尋指令並即時捲動至符合項目；Ctrl+Shift+R 開啟書籤選單，收藏常用指令並一鍵帶入輸入框。

🌐

多語言介面

完整支援英文與繁體中文，可於執行時即時切換，不需重啟。

🔐

多重 AI 供應商

開箱即支援 OpenAI、Anthropic、Google、Ollama（本地端推論）及 OpenAI 相容端點，可依需求切換。也可以直接用訂閱帳號登入——Claude、ChatGPT、Gemini、GitHub Copilot 皆可，不必另外申請 API Key。

🔧

MCP 工具

接上任何 MCP（Model Context Protocol）伺服器，AI 就能直接讀寫檔案、查詢資料、呼叫外部服務，不必經過終端機指令。工具的每一次呼叫與回傳都看得到、展得開。

🔗

Claude Code 橋接

把 Claude Code CLI 接到 AITerm 已設定的任何供應商——用你手邊的 OpenAI、Gemini 或本地模型跑 Claude Code，模型可隨時切換。

📡

遠端終端機 AI 面板

連進同事分享的終端機後，Ask AI 是跟本機一樣的完整對話面板——自由問答、切換 AI 供應商、瀏覽並接續歷史對話，全部走你自己設定的供應商，對方那台不需要有 AI。也能在遠端分頁輸入 /agent，讓 AI 自己規劃、下指令、看結果，一步步完成任務。

📱

Telegram 遠端控制

啟用 Remote 開關，透過 Telegram Bot 從手機傳送指令至終端機，執行結果即時回傳至 Telegram 訊息，隨時隨地掌控你的工作階段。

⚙

需求管理系統

AI 輔助功能討論，自動生成規格文件（SDD）並存入專案結構化目錄，讓想法轉化為可追蹤的規格。

快速安裝

  1. 前往 GitHub Releases 下載最新 .dmg 安裝檔
  2. 開啟 .dmg，將 AITerm 拖入「應用程式」資料夾
  3. 若出現「已損毀，無法打開」，在終端機執行： 
    xattr -cr /Applications/AITerm.app
  4. 重新開啟 AITerm
  1. 前往 GitHub Releases 下載最新 -setup.exe 安裝檔
  2. 執行安裝檔，依照指示完成安裝
  3. 從開始選單或桌面捷徑啟動 AITerm
⚠️ 最低需求：Ubuntu 22.04 LTS（或提供 libwebkit2gtk-4.1 的發行版）。Ubuntu 20.04 及更早版本不支援。
  1. 前往 GitHub Releases，下載 _x86_64.AppImage 或 _amd64.deb
  2. AppImage（免安裝，Ubuntu 22.04+）： 
    chmod +x AITerm_*_x86_64.AppImage && ./AITerm_*_x86_64.AppImage
  3. .deb 套件（Ubuntu 24.04+）： 
    sudo apt install ./aiterm_*_amd64.deb
  1. 前往 GitHub Releases，下載 _aarch64.AppImage 或 _arm64.deb
  2. AppImage（免安裝，Ubuntu 22.04+ ARM）： 
    chmod +x AITerm_*_aarch64.AppImage && ./AITerm_*_aarch64.AppImage
  3. .deb 套件（Ubuntu 24.04+ ARM）： 
    sudo apt install ./aiterm_*_arm64.deb
  1. 在 Telegram 搜尋 @BotFather，輸入 /newbot 建立一個新 Bot，取得 Bot Token
  2. 與你的 Bot 傳送任意訊息，然後開啟瀏覽器訪問以下網址取得 Chat ID： 
    https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
  3. 在 AITerm 開啟「設定」→「Telegram 遠端控制」，填入 Bot Token 與 Chat ID 並儲存
  4. 在終端機狀態列點擊 📱 Remote 開關啟用遠端控制
  5. 現在可以從手機的 Telegram Bot 對話視窗傳送 shell 指令，執行結果將自動回傳至同一對話
